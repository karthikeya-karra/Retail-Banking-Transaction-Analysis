# Retail Banking Transaction Analysis

## Project Overview
A MySQL-based business analytics project focused on analysing retail banking operations and generating actionable business insights.

The project explores customer profiles, account activity, branch performance, transactions, loan performance, repayment behaviour, and card engagement.

## Database Details

**Database:** `retail_banking`

| Table | Records |
|---|---:|
| customers | 500 |
| accounts | 700 |
| branches | 40 |
| loans | 300 |
| loan_payments | 2,000 |
| cards | 600 |
| transactions | 5,000 |
| **Total** | **9,140** |

## Technologies Used
- MySQL
- SQL
- Relational Database Design
- Data Exploration
- Data Analysis

## Project Workflow
1. Analysed business requirements.
2. Studied the Entity Relationship Diagram (ERD).
3. Designed and created relational database tables.
4. Defined primary keys and foreign key relationships.
5. Imported and validated banking datasets.
6. Performed exploratory data analysis.
7. Developed SQL queries to answer business questions.
8. Identified business insights and recommendations.

## Key Analysis Areas
- Customer segmentation and demographics
- Account balances and branch performance
- Transaction types, channels, and trends
- Loan portfolio and outstanding balances
- Loan repayment patterns and late payments
- Card usage and product engagement
- Customer product ownership and cross-selling opportunities

## Business Insights
The analysis is designed to help identify:
- High-value customer relationships
- Customers suitable for additional banking products
- Branch-level account and loan performance
- Potential loan repayment risks
- Customer transaction preferences
- Opportunities to improve product engagement

## Repository Contents
- `Bank_Retail.sql` – Database creation, table definitions, data validation, exploratory analysis, analytical queries, business insights, and recommendations.

## How to Use
1. Install MySQL Server and MySQL Workbench.
2. Clone or download this repository.
3. Open `Bank_Retail.sql` in MySQL Workbench.
4. Review the database creation and table definitions.
5. Import the required datasets into the corresponding tables.
6. Execute the analytical queries to explore the banking data.

**Note:** The SQL script contains the database structure and analysis queries. The underlying CSV datasets are not included in this repository.

## Conclusion
This project demonstrates the application of MySQL in relational database management, data exploration, business analysis, and deriving insights to support retail banking decisions.
